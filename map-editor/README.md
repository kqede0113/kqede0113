# 3Dマップエディタ

ブラウザだけで動く、簡易の 3D マップエディタです。ビルドは不要で、[Three.js r169](https://cdn.jsdelivr.net/npm/three@0.169.0/build/three.module.js) を CDN から読み込みます。

公開後の URL: https://kqede0113.github.io/kqede0113/map-editor/

## ローカルで開く

リポジトリのルートで静的サーバを起動します。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/map-editor/ を開きます（Chrome を想定）。`file://` ではモジュールが読めません。

## 使い方

1. 左のパレットで箱・円柱・球・木・壁・坂・柱・板を選ぶ。
2. 地面を左クリックすると、マスの中心に配置される。カーソル位置に半透明のプレビューが出る。
3. 置いたものを左クリックで選択する。
   - 矢印ギズモで移動（マスにスナップ、高さは自由）
   - **T** または「自由回転」で自由回転、**R** または「90°回転」で Y 軸に 90 度
   - **D** で複製、**Delete / Backspace** で削除、**Esc** で選択解除
4. 視点は右ドラッグで回転、ホイールでズーム、Shift+右ドラッグで平行移動。
5. **歩いて見る**（または **V**）で一人称。WASD で移動、Shift で走る、Space でジャンプ。壁や置いた物体とは直方体で当たり判定する。Esc で編集に戻る。
6. **保存** で `map.json` をダウンロード、**読み込み** で JSON を開く。配置は `localStorage` にも自動保存される。

## 自分のモデル

「ローカルのモデルを追加」からファイル（複数可）またはフォルダを選ぶ。対応は `.glb` `.gltf` `.stl`。

- データはこのブラウザの中だけ（Object URL）。アップロードしない。
- だいたい 1〜2 マスに収まるよう拡大縮小し、地面に接地する。
- STL は Z-up・ミリ単位が多いので、X 軸に -90 度回してからサイズを揃える。
- `.gltf` が外部の `.bin` やテクスチャを参照する場合は、フォルダ選択（または同じ選択に兄弟ファイルを含める）が確実。
- JSON にはファイル名だけを記録する。別のセッションで開くと、同名ファイルを追加するまで橙色の仮箱になる。追加すると自動で差し替わる。

## 保存 JSON

オブジェクトごとに `type` / `paletteId`、`name`、`fileName`（ローカルモデル）、`position`、`rotation`（オイラー角 XYZ、ラジアン）、`scale` を持つ。

## 制限

- スマホ操作は対象外。
- ローカルモデルの実体は JSON や自動保存に含まれない（ファイル名のみ）。
- 当たり判定は軸平行の境界ボックス。坂は斜面ではなく箱として扱う。
- 歩行中のマウス視点は Pointer Lock が許可されたときだけ動く。
- アニメーション付き GLTF は静止ポーズのまま。
